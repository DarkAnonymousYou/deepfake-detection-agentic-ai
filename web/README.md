## 🏃 How to Run the Website Locally

### Option 1: Double-Click Launcher
Double-click `D:\deepfake\start_website.bat`. It will start a local web server and open `http://localhost:3000` in your default browser.

### Option 2: Command Line
```powershell
cd D:\deepfake\web
python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in any browser.

### Option 3: Direct File Open
You can also directly double-click `D:\deepfake\web\index.html` to open it in Chrome, Edge, Brave, or Firefox.

## ☁️ How to Host This Website Online (Like the API)

You have **four 100% free ways** to host this website online so anyone in the world can search and access it directly from their phone or computer:

---

### Option A: Hugging Face Spaces (Static SDK) — Recommended!
Just like your backend API is hosted on Hugging Face Spaces, you can host the website on Hugging Face too with a dedicated, permanent public link:

1. Go to: [**https://huggingface.co/new-space**](https://huggingface.co/new-space)
2. Enter a Space Name (e.g. `deepfake-detector-web` or `veritas-ai-sentinel`)
3. Select **Space SDK: Static** (HTML / CSS / JS) — 100% Free
4. Set Visibility to **Public**
5. Click **Create Space**
6. Double-click [**`D:\deepfake\web\deploy_to_hf_space.bat`**](file:///D:/deepfake/web/deploy_to_hf_space.bat), paste your Space Git URL when prompted, and press Enter!

Your website will immediately be live at:
`https://<your-username>-deepfake-detector-web.hf.space`

---

### Option B: Host Inside Your Existing API Space
Your existing Hugging Face Space (`https://rishi-9858-deepfake-detection-api.hf.space`) can host both the API and the website together:

1. Double-click [**`D:\deepfake\cloud_deployment\push_to_hf.bat`**](file:///D:/deepfake/cloud_deployment/push_to_hf.bat).
2. Enter your Space Git URL (`https://huggingface.co/spaces/rishi-9858/deepfake-detection-api`).
3. Once updated, your website will be live at:
   `https://rishi-9858-deepfake-detection-api.hf.space/web/` (or `/portal`)

---

### Option C: GitHub Pages (1-Click From Your Existing Repo)
1. Double-click [**`D:\deepfake\web\deploy_to_github_pages.bat`**](file:///D:/deepfake/web/deploy_to_github_pages.bat) to push to GitHub.
2. Go to your repo settings:
   `https://github.com/DarkAnonymousYou/deepfake-detection-agentic-ai/settings/pages`
3. Under **Build and deployment**, select **Deploy from a branch**, Branch: `main`, Folder: `/web`, and click **Save**.

Your website will be live at:
`https://DarkAnonymousYou.github.io/deepfake-detection-agentic-ai/web/`

2. Drag and drop the [**`D:\deepfake\web`**](file:///D:/deepfake/web) folder onto the webpage.
