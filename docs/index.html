TRI-MODAL DEEP LEARNING ARCHITECTURE

How Veritas AI Sentinel Works

Standard single-frame CNNs are easily tricked by state-of-the-art diffusion models and GANs. Our tri-modal fusion pipeline audits spatial, frequency, and temporal relationships simultaneously.

01

2D FFT Frequency Analysis

Tensor: (3 × 224 × 224 × 3)

Applies 2D Fast Fourier Transform, high-pass Laplacian filtering, and optical flow to expose microscopic upsampling artifacts, periodic grid noise, and synthetic blending seams invisible in the RGB color domain.

02

Spatial Face Biometrics

Tensor: (10 × 224 × 224 × 3)

Extracts 10 uniformly spaced facial frames cropped with an 18% expanded margin. Audits skin pore texture continuity, ear-lobe boundary blending lines, teeth consistency, and corneal reflection symmetry.

03

Temporal Sequence Dynamics

Tensor: (3 × 5 × 224 × 224 × 3)

Samples 3 multi-frame sequence intervals (5 frames each) to evaluate inter-frame temporal coherence. Detects unnatural micro-jitter, frame-to-frame face warping, and aberrant blink rates.

MULTI-HEAD ATTENTION CORE

Graph Attention Network (GAT-v2.1)

Rather than simply concatenating raw vectors, our Graph Attention Network treats the Spatial, Frequency, and Temporal streams as interconnected nodes in a relational knowledge graph. Multi-head self-attention learns dynamic edge weights between modalities, magnifying subtle cross-domain anomalies.

  • Multi-head relational attention weights between spatial and frequency nodes
  • Temporal edge pooling preventing single-frame false positives
  • Dense classifier with Sigmoid probability calibrated to strict 0.50 threshold

KNOWLEDGE BASE

Frequently Asked Questions

Search answers to common queries regarding model reliability, frequency forensics, and API integration.

Standard deepfake detectors typically rely only on a single spatial CNN frame. AI Sentinel fuses three distinct modalities: (1) 2D FFT Frequency Analysis for synthetic grid noise, (2) Expanded Biometric Face Crops for boundary blending lines, and (3) Temporal Sequences for inter-frame motion. A Graph Attention Network (GAT) computes dynamic cross-modal edge weights.
Generative adversarial networks (GANs) and diffusion models utilize transpose convolutions and upsampling operations that inadvertently introduce high-frequency periodic artifacts and checkerboard patterns. While almost imperceptible in the RGB pixel domain, these artifacts show up distinctly as bright spectral spikes in the frequency domain.
Our cloud inference API accepts MP4, MOV, AVI, WebM, and MKV video files up to 50MB. We recommend clips of 3 to 30 seconds for the most rapid and accurate temporal multi-frame analysis.
To prevent false positive classifications on arbitrary scenery or non-human objects, the system enforces a strict biometric face validation check. If no human face is detected across sampled frames, the API returns a status 422 alert requesting a video with a visible human subject.
When a user provides feedback ("Yes, Accurate" or "No, Incorrect"), the video sample and telemetry payload are automatically logged into our staged active learning pipeline on the backend. This enables continuous fine-tuning on challenging real-world edge cases.
